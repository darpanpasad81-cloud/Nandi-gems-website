# Nandi Gems & Jewels Website

A responsive React + Vite website for Nandi Gems & Jewels.

## Run locally
1. Install Node.js.
2. In this folder, run `npm install`.
3. Run `npm run dev`.

## Build for deployment
Run `npm run build`. The production website is generated in the `dist` folder.

## Vercel deployment
- Import this GitHub repository into Vercel.
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Notes
- The enquiry form opens WhatsApp to +91 79001 38339.
- Product pricing is illustrative and should be updated before publishing.
- Currency toggle changes display formatting only; it is not a live exchange-rate feed.
- Product photography is loaded from Unsplash URLs and needs an internet connection.
- This starter site does not include payment processing, customer accounts, inventory, database storage, GST invoicing, or an admin dashboard.
